Multinomial Naive Bayes

Baseline Machine Learning

Architecture & Preprocessing

To establish a strong, interpretable baseline, we utilized a Multinomial Naive Bayes classifier. Naive Bayes relies on Bayes' Theorem and the naive assumption of conditional independence between features, which surprisingly works very well for text classification.

Pipeline specifics:

  • HTML Stripping and Lowercasing
  • Stopword removal and Porter Stemming (collapsing words like "running" into "run")
  • TF-IDF Vectorization spanning unigrams and bigrams (max 10,000 features).

Results & Error Analysis

The model achieved 84.20% accuracy on the test set.

Limitations: A significant portion of the misclassification stems from sarcasm and negation. Because TF-IDF is a "bag-of-words" model, it entirely ignores word order. Therefore, phrases like "not good" are processed exactly the same as "good", which creates a hard upper limit on the performance of the algorithm.
