Logistic Regression

Machine Learning

Architecture

Logistic Regression serves as our secondary machine learning model. By extracting TF-IDF features and applying an L2-regularized logistic regression, we attempt to draw a linear decision boundary through the high-dimensional text space.

Results

The model achieved approximately 89.5% accuracy, demonstrating that even simple linear models can extract significant predictive power from well-processed TF-IDF matrices.
