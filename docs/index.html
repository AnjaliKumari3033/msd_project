Decoding Sentiment with Machine Learning

A comprehensive analysis of 50,000 IMDB movie reviews using traditional algorithms, Recurrent Neural Networks, and modern Transformer architectures.

Explore the Project

Project Overview

The Objective

The goal of this project is to perform binary sentiment classification on natural language text. By analyzing the raw text of movie reviews, the models must predict whether the underlying sentiment of the reviewer is Positive or Negative.

The Dataset

We utilized the benchmark Large Movie Review Dataset (IMDB). It contains 50,000 highly polar reviews, perfectly balanced between 25,000 positive and 25,000 negative samples, making it an ideal candidate for baseline machine learning research.

Exploratory Data Analysis

Data Quality and Preprocessing

Before any modeling could begin, a thorough audit of the dataset was conducted. The raw text contained thousands of HTML artifacts (such as line break tags) scraped directly from the web. Over 50% of the raw data required systematic cleaning.

A rigorous text cleaning pipeline was implemented across all models to strip HTML entities, normalize whitespace, and remove exact duplicates, ensuring the algorithms learned from pure semantic content.

Dimensionality Reduction

Text data is inherently high-dimensional. To visualize the semantic spread of the reviews, the text was converted into a 5,000-dimensional TF-IDF sparse matrix. Using Truncated Singular Value Decomposition (SVD), these 5,000 dimensions were mathematically compressed down to just 2 dimensions, allowing the distinct clustering of positive and negative vocabularies to be visualized on a standard coordinate plane.

Modeling Architectures

Logistic Regression

Baseline

Feature Extraction: TF-IDF Vectorization

As a baseline machine learning approach, Term Frequency-Inverse Document Frequency was used to map word frequencies. A standard Logistic Regression classifier was then trained to draw a linear decision boundary between the classes.

Bidirectional LSTM

Deep Learning

Architecture: PyTorch RNN

To capture the sequential nature of language, a Long Short-Term Memory (LSTM) neural network was built from scratch. By reading the sequences in both directions (Bidirectional), the model captures deeper contextual dependencies over time.

BERT

State-of-the-Art

Architecture: Transformer

The state-of-the-art approach involved fine-tuning the pre-trained bert-base-uncased model from Google. Utilizing self-attention mechanisms, BERT understands the nuanced context of every word relative to the entire sentence.

Conclusion

This project successfully demonstrates the evolution of Natural Language Processing techniques.

From sparse matrix representations and linear classifiers to complex recurrent sequences and modern self-attention transformers, the results highlight the significant performance gains achieved by allowing models to understand the deeper context of human language.
