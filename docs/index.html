Core Foundation

1. Problem Statement (PS) & Research Topic

Sentiment analysis is one of the most critical and challenging tasks in Natural Language Processing (NLP). This project formulates sentiment understanding beyond simple polarity into a comprehensive multi-paradigm study.

The Central Research Question

How accurately can machine learning algorithms infer human sentiment and predict exact numerical star ratings from unstructured natural language text, and where do traditional statistical boundaries fail compared to contextual Deep Learning architectures?

Why Natural Language Sentiment is Difficult

NLP Complexity

Analyzing raw movie reviews introduces severe real-world linguistics challenges that break simplistic word-matching systems:

1. Negation & Sarcasm

Phrases like "not bad at all", "this movie was anything but boring", or sarcastic praise ("A true masterpiece of terrible directing") fool unigram models because individual negative words appear in positive contexts and vice-versa.

2. Fine-Grained Rating Nuance

Moving from binary (positive/negative) to continuous 1–10 regression requires decoding subtle adjective intensifiers—distinguishing between a "7/10" review ("pretty solid") and an "8/10" review ("incredibly gripping").

3. Length & Sparsity Variance

Review lengths span from 32 characters to over 13,700 characters. Bag-of-words representations generate high-dimensional sparse matrices exceeding 80,000 dimensions with over 99% zero entries.

The Three Machine Learning Paradigms Investigated

Comprehensive Scope

Paradigm 1: Binary Classification

Classifying text strictly into Positive (1) or Negative (0). Evaluated using Multinomial Naive Bayes, Logistic Regression, Bidirectional LSTM, and fine-tuned BERT.

Paradigm 2: Continuous Regression

Predicting the exact continuous 1–10 star score. Formulated with Mean Squared Error (MSE) loss using XGBoost Regressor, LSTM Regressor, and BERT Continuous Regressor.

Paradigm 3: Unsupervised Clustering

Discovering natural latent sentiment profiles in completely unlabelled text using Truncated SVD dimensionality reduction, K-Means Clustering, and Gaussian Mixture Models (GMM).

Data Engineering

2. Dataset Engineering & Sourcing

The project builds upon the benchmark Large Movie Review Dataset (IMDB) comprising 100,000 text reviews, systematically partitioned into three dedicated research subsets.

Binary Classification Data

50,000 Samples

Extracted strictly from the pos and neg subdirectories. Labels (1 = positive, 0 = negative) were derived from directory structure.

  • Training split: 25,000 reviews (12,500 pos / 12,500 neg)
  • Testing split: 25,000 reviews (12,500 pos / 12,500 neg)
  • Balance: Perfectly 50/50 balanced to prevent bias

Continuous Regression Data

50,000 Samples

Engineered by parsing the exact 1–10 numerical rating score embedded in the raw filename metadata (e.g., 1234_7.txt → rating = 7).

  • Target Space: Exact continuous float / integer [1.0 – 10.0]
  • Distribution: Bimodal U-shaped rating curves
  • Objective: Minimizing Mean Absolute & Squared Error

Unsupervised Clustering Data

50,000 Samples

Extracted from the train/unsup directory, stripped of all sentiment labels and filename rating metadata.

  • Target Space: Completely unlabelled text
  • Purpose: Unsupervised semantic discovery sandbox
  • Algorithms: Truncated SVD, K-Means, and GMM
Text Normalization

3. Data Cleaning & Feature Preprocessing Pipeline

Raw web-scraped reviews were heavily contaminated with HTML artifacts. An initial data audit revealed HTML tags in over 58% of reviews and duplicate submissions. We implemented a strict, deterministic cleaning sequence.

1

HTML Entity Unescaping

Used Python's html.unescape() to translate encoded entities (such as &amp; → &, &quot; → ") back to their genuine ASCII character equivalents, restoring true reviewer intent.

2

Regex HTML Tag Stripping

Over 58.7% of training reviews contained <br /> breaks and embedded HTML elements. Regular expressions (<br\s*/?> and <[^>]+>) stripped structural tags to ensure models learn natural semantics rather than HTML scraping artifacts.

3

Whitespace & Encoding Normalization

Multiple consecutive spaces, non-breaking spaces, and hidden carriage returns were collapsed into uniform single spaces, preventing identical tokens from splitting due to invisible formatting.

4

Deduplication (Preventing Data Leakage)

A rigorous audit identified duplicate reviews resulting from automated crawler scraping. We permanently removed 96 duplicate entries from the training set and 199 from the test set, eliminating sample memorization and data leakage between splits.

5

Dual Architecture-Specific Vectorization

Because algorithms cannot digest raw strings, text was numerically vectorized along two distinct architectural branches:
• Statistical Models (Naive Bayes, Logistic, XGBoost, SVD, K-Means): Transformed via TF-IDF with unigrams and bigrams (ngram_range=(1,2)) to capture phrase-level negation while penalizing generic stopwords.
• Deep Learning & Transformers (BiLSTM, BERT): Encoded into integer sequence matrices (BiLSTM) and subword WordPiece token IDs with positional attention embeddings (BERT) to retain temporal sequence and deep bidirectional context.
