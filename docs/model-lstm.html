Bidirectional LSTM

Deep Learning Sequence Model

Architecture & Preprocessing

To overcome the limitations of "bag-of-words" models, we implemented a Long Short-Term Memory (LSTM) Neural Network built entirely from scratch using PyTorch.

Pipeline specifics:

  • Dynamic Vocabulary Building: Mapping the 25,000 most frequent words to integer tokens.
  • Embedding Layer: Learning 128-dimensional dense vector representations for every word.
  • 2-Layer Bidirectional processing: Reading the sequences left-to-right and right-to-left.

Training & Results

The model was trained for a maximum of 20 epochs with an Early Stopping patience of 3 to prevent overfitting.

It achieved 87.78% accuracy. While this is lower than Logistic Regression, it is notable because the LSTM learned the structural relationships of language completely from scratch without relying on statistical hacks like TF-IDF.
