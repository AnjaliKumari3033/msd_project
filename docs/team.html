Meet Our Team

We are 3rd year B.Tech students at IIT Dharwad. This website presents our work for the Multidisciplinary Data Science (MDS) course project on sentiment analysis and rating prediction.

MEMBER 01
AK

Anjali Kumari

Project Lead

Led the overall project and fine-tuned the BERT Transformer for both binary classification (94.16% accuracy) and rating prediction (0.9897 MAE). Coordinated tasks across the team, managed the repository, and compiled the LaTeX project report.

BERT Transformers PyTorch AdamW Optimization Transfer Learning Project Coordination
MEMBER 02
TR

Tangirala Dhanunjaya Rao

Built and trained the 2-layer Bidirectional LSTM in PyTorch for classification (87.78% accuracy) and the continuous LSTM regressor (1.5477 MAE). Analyzed prediction residuals and developed this website to present our project findings and plots.

Bidirectional LSTM Continuous Regression PyTorch GPU Residual Analysis Web Deployment
MEMBER 03
PP

Paripelly Pritika

Wrote Python extraction scripts to parse all 100,000 reviews from the raw IMDB directories. Handled data preprocessing: removed HTML <br /> tags (present in ~58% of reviews), unescaped characters, normalized whitespace, and removed duplicate reviews to avoid data leakage. Generated the EDA distribution plots.

Corpus Extraction Regex Normalization Deduplication Exploratory Data Analysis Pandas
MEMBER 04
SK

Sucharitha Kamera

Implemented and benchmarked our baseline ML models: Multinomial Naive Bayes (84.20% accuracy) and Logistic Regression with TF-IDF unigrams and bigrams (88.22% accuracy). Evaluated how bigrams help capture phrases like “not good”.

Multinomial Naive Bayes Logistic Regression TF-IDF Vectorization N-Gram Parsing Scikit-Learn
MEMBER 05
HK

Harshith Konda

Handled the unsupervised learning and dimensionality reduction tasks. Reduced TF-IDF features to 2 components using Truncated SVD for 2D plotting. Implemented K-Means clustering (confirming K=2 with the elbow curve) and tested Gaussian Mixture Models (GMM) for soft clustering on mixed reviews.

Truncated SVD K-Means Clustering Gaussian Mixture Models Dimensionality Reduction Latent Semantics
