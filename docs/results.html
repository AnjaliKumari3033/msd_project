[01] Task

Binary Sentiment Classification

Four models of increasing complexity were trained on 50,000 balanced reviews (25,000 for training and 25,000 for testing) to predict whether a review is positive or negative. Moving from simple word counts to BERT’s contextual understanding improved accuracy by 9.96 percentage points (84.20% to 94.16%).

Model Representation Accuracy Precision Recall F1-Score Remarks
Multinomial Naive Bayes Bag-of-Words (word counts) 84.20% — — — Simple baseline from report Table I; word independence assumption means precision, recall and F1 were not reported.
Logistic Regression TF-IDF (unigrams + bigrams, C = 1.0) 88.22% 0.88 0.88 0.88 Bigrams capture short phrases such as “not good”, giving a strong linear baseline.
Bidirectional LSTM 128-dim embeddings, 2-layer BiLSTM 87.78% 0.88 0.88 0.88 Reads text in order, but loses information on long reviews (200+ words).
BERT (Fine-Tuned) WordPiece tokens + self-attention 94.16% 0.94 0.94 0.94 Best model; self-attention understands context, sarcasm and negation across the whole review.

Multinomial Naive Bayes

Accuracy 84.20%

Naive Bayes counts how often each word appears and assumes all words are independent of each other. It is fast and makes a good baseline, but because it ignores word order it cannot understand negation (“not good”) or sarcasm. This is why it scored the lowest of the four models.

Logistic Regression

Accuracy 88.22%

We used TF-IDF features with unigrams and bigrams and L2 regularization (C = 1). TF-IDF reduces the weight of very common words, and bigrams like “worst movie” keep a little word-order information. This simple model gave a surprisingly strong 88.22% and even slightly beat our BiLSTM.

Bidirectional LSTM

Accuracy 87.78%

This is a 2-layer BiLSTM built in PyTorch that reads each review both forwards and backwards using 128-dimensional word embeddings. It learns word order and grammar from scratch, but reviews are long (over 200 words on average), and LSTMs tend to forget early parts of long text. Because of this it did not beat Logistic Regression.

BERT (bert-base-uncased)

Accuracy 94.16%

We fine-tuned the pre-trained BERT model for 3 epochs on our reviews (transfer learning). Self-attention lets every word look at every other word in the review, so BERT understands context, negation and sarcasm much better than the other models. It gave the best results, with only 820 false positives and 629 false negatives on the test set.

Figure 1.1 Confusion matrix for fine-tuned BERT on the test set (11,540 true negatives, 11,810 true positives, 820 false positives, 629 false negatives), giving 94.16% accuracy.
Figure 1.2 Confusion matrix for the 2-layer Bidirectional LSTM. It handles clearly positive or negative reviews well, but makes more mistakes on mixed-sentiment reviews than BERT.
Figure 1.3 Training and validation loss curve for the Bidirectional LSTM. Early stopping was used to stop training before the model started overfitting.
[02] Task

Rating Prediction (1–10 Scale)

Here the goal is to predict the exact rating (1–10) a user gave, which is harder than simple positive/negative classification. For the deep learning models, the classification layer was replaced with a single output node trained using Mean Squared Error (MSE) loss.

Model Loss Function MSE MAE R² Score Average Error
XGBoost Regressor Squared error (TF-IDF, 2,000 features) 6.5666 2.1612 0.4604 ± 2.16 rating points
LSTM Regressor MSE loss (linear output layer) 4.8040 1.5477 0.6058 ± 1.55 rating points (28.4% lower MAE than XGBoost)
BERT Regressor (Fine-Tuned) MSE loss (single output node, num_labels=1) 2.2462 0.9897 0.8154 ± 0.99 rating points (under 1 point)

XGBoost Regressor

MAE 2.1612 • R² 0.4604

XGBoost builds many small decision trees one after another, where each tree fixes the mistakes of the previous ones. We trained it on 2,000 TF-IDF features (unigrams and bigrams). Since it only sees word frequencies and not word order, it is off by about 2 rating points on average, making it our weakest regression model.

LSTM Regressor

MAE 1.5477 • R² 0.6058

We reused the LSTM architecture with a single linear output and MSE loss so it predicts a number instead of a class. Because it reads the review as a sequence, it improved a lot over XGBoost (MAE from 2.16 to 1.55). It still struggles to tell close ratings apart, such as 7 versus 8.

BERT Regressor

MAE 0.9897 • R² 0.8154

We fine-tuned bert-base-uncased for 3 epochs after replacing the classification head with one output node and using MSE loss. MSE penalizes large mistakes more, so predicting 8 for a true 9 is better than predicting 2. BERT’s understanding of context gave the best result: the average prediction is less than one rating point away from the true rating.

Figure 2.1 BERT regression training and validation MSE over 3 epochs, showing stable training and a final test MSE of 2.2462.
Figure 2.2 True ratings vs. predicted ratings for the LSTM regressor. Points closer to the diagonal line are better predictions.
Figure 2.3 Distribution of prediction errors (predicted rating minus true rating) for the LSTM regressor. The errors are centered near zero, so the model does not consistently over- or under-predict.
[03] Task

Dimensionality Reduction & Clustering

We also checked whether positive and negative reviews naturally separate without using any labels. Truncated SVD was used to reduce the TF-IDF features to 2 dimensions for plotting, and K-Means and Gaussian Mixture Models were used to group the 50,000 unlabelled reviews.

Model / Method Learning Paradigm Input → Output Target / Criterion Supervised Metric Key Finding from Report
Truncated SVD Dimensionality Reduction 5,000+ TF-IDF → 2 Components Variance Maximization — 2D scatter plot confirms that latent semantic structures align with sentiment polarity.
K-Means Clustering Unsupervised (Hard Partitioning) 50,000 unlabelled reviews (K = 2) WCSS Inertia Minimization — Elbow curve clearly bends at K = 2, confirming a natural two-group sentiment structure.
Gaussian Mixture Model (GMM) Unsupervised (Soft Probabilistic) 50,000 unlabelled reviews (2 Gaussians) Expectation-Maximization (EM) — Assigns continuous probabilities to mixed reviews (e.g., 60% positive, 40% negative).

Truncated SVD

Dimensionality Reduction

TF-IDF creates thousands of features per review, which is hard to visualize. Truncated SVD compresses them into just 2 principal components so every review can be drawn as a point on a 2D plot. Even with this heavy compression, positive and negative reviews show visible separation.

K-Means Clustering

Hard Clustering

K-Means groups reviews into K clusters by placing each review in the cluster with the nearest center. We used the elbow curve to choose K, and it points to K = 2, which matches the positive/negative split. Its limitation is that every review must belong fully to one cluster, even if its opinion is mixed.

Gaussian Mixture Model (GMM)

Soft Clustering

GMM models each cluster as a Gaussian distribution and gives every review a probability for each cluster (for example 60% positive and 40% negative). This works better for reviews that contain both praise and criticism, since they are not forced into a single group.

Figure 3.1 Truncated SVD 2D projection (PC1 vs. PC2) of the TF-IDF features. Positive and negative reviews show distinct regions, which suggests sentiment is a major source of variation in the text.
Figure 3.2 K-Means elbow curve (inertia for K = 1 to 10). The bend at K = 2 supports the two-group positive/negative structure.
Figure 3.3 Gaussian Mixture Model soft-clustering probabilities, showing how mixed-opinion reviews sit between the two clusters.

[05] Observations

Key Observations from the Data

OBSERVATION 01 Rating Distribution

Ratings Are Mostly at the Extremes

The 1–10 rating histogram is U-shaped, and ratings 5 and 6 are almost completely missing. The IMDB benchmark dataset leaves out neutral reviews on purpose so that every review is clearly positive or negative. People also tend to write reviews when they feel strongly, so most ratings are 1 or 10.

Takeaway: With so few mid-range ratings, regression models rarely see examples in the middle of the scale, which makes middle-range predictions harder.
OBSERVATION 02 Writing Style

Angry Reviews Use More Exclamation Marks and CAPS

Our analysis showed that 1-star reviews use clearly more exclamation marks (!!!) and ALL-CAPS words than 10-star reviews. Unhappy reviewers tend to stress their opinion with punctuation and capital letters, while happy reviewers mostly use positive adjectives.

Takeaway: How people write (punctuation and capitalization) carries useful information about sentiment, not just what words they use.
OBSERVATION 03 Review Length

Strong Opinions Lead to Longer Reviews

Reviews with extreme ratings (1-star and 10-star) are longer on average than moderate ones. When someone feels very strongly, they tend to explain their reasons in detail, while mild opinions are usually short summaries.

Takeaway: Long reviews are harder for the BiLSTM, which forgets earlier words, while BERT’s self-attention can look at the whole review at once.
OBSERVATION 04 High-Dimensional Text

TF-IDF Features Are Very Sparse

TF-IDF turns each review into thousands of features, and most of them are zero because any one review uses only a small part of the vocabulary. Very common words such as “movie” and “film” appear everywhere, so they do not help in telling positive and negative reviews apart.

Takeaway: Truncated SVD reduced the 5,000 TF-IDF features to 2 components, which made it possible to visualize the reviews and still showed a visible sentiment separation.
OBSERVATION 05 Model Comparison

The BiLSTM Did Not Beat Logistic Regression

Our 2-layer BiLSTM reached 87.78% accuracy, slightly below Logistic Regression with bigrams (88.22%). Movie reviews are long (over 200 words on average), and LSTMs find it hard to remember information from the start of a long text, so their extra complexity did not pay off here.

Takeaway: BERT solved this problem with self-attention and reached 94.16% accuracy.
OBSERVATION 06 Clustering

Mixed Reviews Are Hard to Put in One Cluster

Some reviews contain both praise and criticism, for example “Superb acting, but an incoherent mess of a plot”. K-Means has to place such a review in exactly one cluster, while Gaussian Mixture Models give it a probability for each cluster (for example 60% positive and 40% negative).

Takeaway: Soft clustering with GMM suits real-world opinions better than hard clustering.
