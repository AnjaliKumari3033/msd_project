\section{Introduction}
This report details the end-to-end machine learning pipeline designed to extract, analyze, and predict sentiment and continuous ratings from the Large Movie Review Dataset (IMDB). The overarching objective is to contrast traditional statistical models against modern Deep Learning architectures. The project spans three major machine learning paradigms:
\begin{enumerate}
    \item \textbf{Binary Classification}: Predicting Positive (1) vs. Negative (0) sentiment.
    \item \textbf{Continuous Regression}: Predicting the exact rating (1-10) using advanced Transformer adaptation and XGBoost.
    \item \textbf{Unsupervised Learning}: Identifying latent structures via Dimensionality Reduction, K-Means, and Gaussian Mixture Models (GMM).
\end{enumerate}

\section{Methodology: Binary Classification Models}
The binary classification task utilized a perfectly balanced dataset of 50,000 labeled reviews (25,000 Positive, 25,000 Negative). We implemented models across the complexity spectrum.

\subsection{Traditional Statistical Methods}
\textbf{Multinomial Naive Bayes} yielded a baseline accuracy of 84.20\%. While fast, it relies heavily on word frequencies and fails on syntactic structures like negation due to the conditional independence assumption. \textbf{Logistic Regression}, employing L2 regularization and TF-IDF vectorization, established a stronger statistical baseline with an accuracy of 89.50\%.

\subsection{Bidirectional LSTM}
To capture temporal dependencies, we implemented a Bidirectional LSTM. By utilizing memory gates, the LSTM reads text forward and backward, capturing grammar and syntax inherently without manual TF-IDF feature engineering. The LSTM achieved 87.78\% accuracy. The hidden state update in an LSTM is defined as:
\begin{equation}
    h_t = o_t \odot \tanh(c_t)
\end{equation}

\subsection{BERT Classification (Transformer)}
State-of-the-art performance was achieved by fine-tuning the \texttt{bert-base-uncased} transformer model. BERT perfectly grasps the context of every word relative to the entire sentence using self-attention mechanisms, overcoming sarcasm and negation limitations.
The model achieved an outstanding test accuracy of \textbf{94.16\%}. The self-attention matrix calculation is fundamentally defined as:
\begin{equation}
    \text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V
\end{equation}

\section{Methodology: Continuous Regression Models}
Predicting the exact 1-10 rating introduces a much higher degree of difficulty compared to binary sentiment. Identifying a ``7/10'' review versus an ``8/10'' review requires an extremely nuanced understanding of qualifiers.

\subsection{XGBoost Regression}
Operating on TF-IDF features, XGBoost builds an ensemble of decision trees to map linguistic features to the continuous rating scale. By minimizing the objective function, XGBoost proved highly effective at extracting linear and non-linear boundaries from the sparse term-frequency matrix.

\subsection{Attention-Augmented LSTM}
An LSTM augmented with an Attention mechanism was trained using Mean Squared Error (MSE) loss. Unlike the classification LSTM, the continuous objective function penalizes the model based on the absolute distance of the prediction from the true rating.

\subsection{BERT Regression}
We repurposed the pre-trained \texttt{bert-base-uncased} model for regression by modifying the final layer to a single continuous linear output node (\texttt{num\_labels=1}). By training with MSE Loss over 3 epochs, BERT again demonstrated superior contextual awareness, yielding the lowest Mean Absolute Error (MAE) among the regression models.

\section{Dimensionality Reduction}
Text data vectorized via TF-IDF is inherently high-dimensional and sparse. To satisfy the Dimensionality Reduction requirements, we applied \textbf{Truncated Singular Value Decomposition (SVD)}. 
\begin{itemize}
    \item We compressed the 5,000-dimensional TF-IDF space down to just 2 Principal Components.
    \item Plotting the reviews on an X/Y scatter plot using these two components revealed distinct clustering of negative and positive vocabularies, despite the extreme compression.
\end{itemize}

\section{Conclusions}
The progression of predictive power throughout this project perfectly illustrates the evolution of Natural Language Processing. Traditional models (Naive Bayes) struggle with context, viewing documents as mere ``bags of words.'' Recurrent neural networks (LSTMs) introduce sequence and time, but struggle with long-term dependencies. Finally, Transformers (BERT) solve both issues simultaneously through bidirectional self-attention, achieving 94.16\% classification accuracy and mastering the highly nuanced continuous regression task.
