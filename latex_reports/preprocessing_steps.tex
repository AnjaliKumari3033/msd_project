\section{Introduction}
Natural language text scraped from the web is inherently noisy. Over 50\% of the raw IMDB movie reviews contained HTML artifacts (e.g., \texttt{<br />}), non-standard punctuation, and inconsistent whitespace. A robust, deterministic preprocessing pipeline was essential to prepare the data for downstream machine learning tasks, from Multinomial Naive Bayes to BERT and K-Means.

\section{Data Extraction}
The raw dataset was provided as individual text files nested within subdirectories based on sentiment and split.
\begin{itemize}
    \item \textbf{Binary Classification Data}: Extracted from \texttt{train/pos}, \texttt{train/neg}, \texttt{test/pos}, and \texttt{test/neg}. The parent folder dictated the 1 or 0 binary label.
    \item \textbf{Continuous Regression Data}: Ratings (1-10) were extracted directly from the filenames (e.g., \texttt{1234\_7.txt} corresponds to a rating of 7).
    \item \textbf{Unsupervised Data}: 50,000 unlabelled reviews extracted from the \texttt{train/unsup} folder for Truncated SVD, K-Means, and Gaussian Mixture Model (GMM) clustering.
\end{itemize}

\section{Deduplication}
After aggressive cleaning, several reviews collapsed into identical strings. We performed strict deduplication on the \texttt{text\_clean} column to prevent data leakage and artificially inflated metrics, removing several hundred duplicate entries across the subsets.
